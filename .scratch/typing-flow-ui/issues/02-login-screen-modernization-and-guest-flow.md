# 02 — Login Screen Modernization and Prominent Guest Flow

**What to build:** Revamp the login card so that guest practice is an obvious, first-class choice rather than an inconspicuous secondary link. Clearly separate the credential authentication form from the guest option with an explicit divider. Present "Continue as Guest" as an inviting full-width action with an explanatory note explaining that typing history is stored locally in the browser. Provide convenient quick-fill buttons for the default admin credentials.
