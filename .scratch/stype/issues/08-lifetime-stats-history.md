# 08 — Lifetime Stats & Test History Dashboards

**What to build:** Dashboards that let users review their historical performance. A History page lists past individual test runs, while a Stats page calculates their all-time aggregate performance (like average WPM and peak WPM).

**Blocked by:** 03 — Test Run Persistence

**Status:** ready-for-agent

- [x] A Test History page lists past completed test runs.
- [x] History list supports filtering by date and test mode.
- [x] A Lifetime Stats page displays total tests completed, average WPM, peak WPM, and average accuracy.
- [x] Metrics are correctly calculated from the user's persisted database records.
