# 02 — Guest Mobile Navigation Menu

**What to build:** An accessible mobile navigation dropdown menu in the Guest Header so unauthenticated Guests on mobile viewports can navigate to all application sections.

**Blocked by:** None — can start immediately.

**Status:** completed

- [x] Mobile viewports render a navigation menu button in the Guest Header.
- [x] Opening the mobile menu displays navigation links to History (`/history`), Stats (`/stats`), Passages (`/passages`), and Settings (`/settings`).
- [x] The mobile menu provides a theme toggle (Light, Dark, System) and a direct link to the Login page (`/app/login`).
- [x] Navigation links within the mobile menu navigate to the correct routes and dismiss the menu on selection.
- [x] Tests verify that the mobile menu renders and operates correctly on mobile viewports.
